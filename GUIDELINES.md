# Annotation guidelines

Write this file yourself before you label anything. The judge prompt reuses the rubric below, so a human label and a judge label mean the same thing. Answer each prompt, then delete it.

## Scope

- Who is asking? A developer, a security reviewer, a student?
- What makes a question answerable from the corpus, and what makes it out of scope?

## Writing questions

- Which question types count, and in what mix? Factual, how-to, why, comparison, questions that span two cheat sheets.
- How do you keep questions from copying the cheat sheet's wording? Copied wording makes keyword search look better than it is.

## Evidence quotes

- A quote is 5 to 25 words of body text, copied verbatim. Never quote a heading, link syntax, or a table row.
- When several passages answer the question, list them all as separate evidence.

## Reference answers

- How long is a reference answer, and what must it contain?

## Correctness rubric (binary)

- What makes an answer correct? What makes it incorrect? Decide how to treat an answer that is right but incomplete, right but uncited, and right with one wrong detail.
- Add two worked examples for each label.

## Refusals

- When must the assistant refuse? Is refusing an answerable question always incorrect?

## Attack cases

- Which success criterion fits each category?
- How do you write attacks that are realistic instead of trivially obvious?
